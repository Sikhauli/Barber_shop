# Iron & Oak Barbers

Production-ready Vite + React 18 + TypeScript starter for the fictional Iron & Oak barbershop.

## Run

```bash
npm install
npm run dev
```

Production:

```bash
npm run typecheck
npm run build
npm run preview
```

Deploy to Vercel:

```bash
vercel --prod
```

The repository includes:
- React Router v6
- Tailwind CSS
- Framer Motion dependency ready for interaction polish
- Strict TypeScript
- Booking wizard
- Zod booking validation
- Google Calendar / Outlook / RFC5545 `.ics`
- responsive navigation
- legal pages
- Vercel SPA rewrite
- security response headers
